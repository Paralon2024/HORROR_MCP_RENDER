# Horror 2D Cartoon Shorts MCP (Render Edition)

Zero-API-key MCP server that generates 60-second vertical 2D horror cartoon shorts using local layered puppet sprites, free `edge-tts` narration, procedural horror audio, and MoviePy video rendering.

## Deploy to Render
1. Push this folder to a GitHub repository.
2. Open Render Blueprints, select your repo, and click **Apply**.
3. Update `mcp.json` with your live `https://<your-app>.onrender.com/sse` URL.
